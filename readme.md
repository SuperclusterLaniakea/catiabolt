# 螺栓全面技术指南：标准、精度、尺寸计算与 Python 参数化建模

> 本项目仿照 `E:\CATIABOLT\refproject`（螺母参数化建模工具）编写，
> 用于在 CATIA V5 中批量生成**全部种类、全部精细程度（精度等级）、
> 英制与公制**的螺栓参数化三维模型。

## 一、螺栓的主要种类与标准体系

### 1.1 按头部结构型式分类

| 类型 | 说明 | 典型标准 |
|------|------|----------|
| **六角头螺栓（全螺纹）** | 最常用，杆部全长螺纹 | GB/T 5782、ISO 4014、DIN 933 |
| **六角头螺栓（部分螺纹）** | 光杆 + 末端螺纹，有定位作用 | GB/T 5783、ISO 4017、DIN 931 |
| **六角法兰面螺栓** | 六角头 + 底部法兰盘，防松好 | GB/T 5787.2、DIN 6921、ISO 10667 |
| **内六角圆柱头螺钉** | 圆柱头 + 顶部内六角孔，占用小 | GB/T 70.1、ISO 4762、DIN 912 |
| **内六角沉头螺钉** | 90° 沉头锥面，安装后齐平 | GB/T 70.3、ISO 4758、DIN 915 |
| **内六角杯头螺钉** | 半球形杯头，外观圆滑 | GB/T 70.4、ISO 4759、DIN 917 |
| **内六角全六角螺钉** | 外六角 + 内六角孔，双驱动 | GB/T 70.2（近似） |
| **方头螺栓** | 方形头，用于槽钢/木结构 | GB/T 5787、近似 ISO 4028 |
| **圆柱头螺栓** | 圆柱头顶部圆滑，薄板连接 | GB/T 818、近似 ISO 4023 |
| **沉头螺栓** | 90° 沉头，安装后无突出 | GB/T 5780、近似 ISO 4030 |
| **半沉头螺栓** | 盘头 + 锥面过渡 | GB/T 5785（近似） |
| **马车螺栓** | 圆头 + 方颈防旋转 | GB/T 5781（近似） |
| **吊环螺栓** | 顶部吊环，用于吊装 | GB/T 823（近似） |
| **双头螺柱** | 两端螺纹 + 中间光杆 | GB/T 896、ISO 899、DIN 976 |
| **翼形螺栓** | 蝶翼手拧，免工具拆装 | GB/T 25159（近似） |

### 1.2 螺纹体系（英制 / 公制 · 粗牙 / 细牙 / 超细牙）

本工具内置 **7 大螺纹标准库**，覆盖全部精细程度：

| 体系 | 名称 | 牙型角 | 单位 | 覆盖规格 |
|------|------|--------|------|----------|
| **公制粗牙** | M Coarse | 60° | mm | M1.6 ~ M48 |
| **公制细牙** | M Fine | 60° | mm | M3×0.5 ~ M48×3 |
| **公制超细牙** | M Extra Fine | 60° | mm | M6×0.5 ~ M48×2 |
| **英制 UNC** | Unified Coarse | 60° | inch | 1/8"-40 ~ 2"-4.5 |
| **英制 UNF** | Unified Fine | 60° | inch | 1/8"-44 ~ 2"-12 |
| **英制 UNRF** | Unified Extra Fine | 60° | inch | 1/4"-36 ~ 2"-20 |
| **英制 BSW** | 惠氏 Whitworth | 55° | inch | 1/8" ~ 2" |

> 英制由 TPI（每英寸牙数）换算螺距：`螺距 = 25.4 / TPI`；
> 公制/UN 牙型角 60°，BSW 惠氏螺纹牙型角 55°——切换螺纹体系时
> 程序会自动带出正确的牙型角参与几何计算。

## 二、精度等级体系（全部精细程度）

### 2.1 螺纹公差带（外螺纹 4g ~ 10g）

螺栓（外螺纹）的螺纹公差带决定牙顶/牙底的极限偏差：

| 公差带 | 含义 | 适用场合 |
|--------|------|----------|
| **4g** | 精密级，公差最小 | 高精度仪器、航空航天 |
| **5g** | 精密级，公差较小 | 精密机械 |
| **6e** | 较松公差 | 厚镀层（如热浸镀锌） |
| **6f** | 中等偏松 | 中等镀层 |
| **6g** | **中等精度（最常用）** | 与螺母 6H 标准配合 |
| **6h** | 中等偏紧，上偏差为零 | 无镀层精配合 |
| **8g** | 较松公差 | 长螺纹、厚镀层 |
| **10g** | 很松公差 | 粗犷连接 |

### 2.2 产品等级（A / B / C 级）

| 等级 | 适用范围 |
|------|----------|
| **A 级** | 螺纹直径 D≤M16，精密机器设备 |
| **B 级** | 螺纹直径 D>M16，一般机械 |
| **C 级** | 表面粗糙、精度要求不高的建筑钢结构 |

## 三、尺寸计算与公称尺寸

### 3.1 关键尺寸参数

- **D**：螺纹公称直径（螺栓大径 / 杆部直径）
- **P**：螺距
- **s**：对边宽度（六角/方头扳手尺寸）
- **e**：对角宽度（六角 e = 2s/√3；方头 e = s·√2）
- **k**：头部高度
- **L**：公称长度（含头部）
- **L₁**：螺纹长度（部分螺纹时）
- **dm₁ / dk**：圆柱头外径 / 沉头头径

### 3.2 外螺纹牙型关键公式

```
牙高   h = 5H/8，H = P / (2·tan(α/2))
60° 公制/UN：h ≈ 0.54127·P
55° BSW：    h ≈ 0.64033·P
小径   d₁ = D - 2h
牙型半底宽 = 5P/16（与牙型角无关）
```

## 四、软件架构与使用说明

### 4.1 文件结构

```
boltproject/
├── readme.md              本文档
├── requirements.txt       依赖（PyQt6 / pywin32）
├── run.bat                一键启动脚本
└── src/
    ├── bolt_data.py       螺栓类型 / 螺纹体系 / 精度等级 / 尺寸库（纯 Python）
    ├── bolt_geometry.py   全类型几何计算 → 建模步骤（与 CATIA 解耦）
    ├── catia_controller.py CATIA V5 COM 自动化（外螺纹 Groove 旋转切除）
    ├── ui_app.py          PyQt6 图形界面
    └── run.py             程序入口
```

### 4.2 使用方法

1. 安装依赖：`pip install -r requirements.txt`
2. 打开 CATIA V5（支持自动化/COM）
3. 运行 `run.bat` 或 `python src\run.py`
4. 左侧树选择螺栓类型 → 选择螺纹体系与规格（公英制、粗牙/细牙/超细牙）→
   选择公差带（4g~10g）/产品等级/性能等级 → 修改参数 → 「绘制到 CATIA」

### 4.3 建模坐标系约定（与螺母项目一致）

```
z = 0   -> 头部顶面（草图基准面 = PlaneXY）
z = -k  -> 头部底面 / 全螺纹起点
z = -L  -> 螺栓末端（螺纹收尾 + 末端倒角）
```

### 4.4 外螺纹的"真几何"实现

CATIA 的 Hole/Thread 特征在 late-binding 下**只写螺纹属性、不生成齿形**，
因此本项目沿用螺母项目的 Groove（旋转切除）方案并**反转牙型方向**：

| | 螺母（内螺纹） | 螺栓（外螺纹） |
|---|---|---|
| 牙型三角形顶点 | 大径侧（向孔外切） | **小径侧（向轴心切）** |
| 牙型三角形底边 | 小径侧 | 大径侧 |
| 效果 | 孔壁留 V 形牙 | 杆壁留 V 形牙 |

在 ZX 平面（草图坐标 h=z, v=x）按螺距绘制 N 个 60°/55° 牙型三角形，
一次 Groove 绕 Z 轴 360° 旋转切除，即得真实 ISO 三角形外螺纹齿形。

### 4.5 批量生成

点击「批量测试全部类型」可自动遍历 15 类螺栓、使用各自默认规格逐一在
CATIA 中建模，用于验证控制器与各类型的几何稳定性。
